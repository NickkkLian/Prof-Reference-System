What this is
{{ app_name }} answers one question for one course: does a student meet the professor's stated conditions for a reference letter — on the roster, grade at or above the threshold, attendance at or above it in every enrolment. It was built for a faculty client (name withheld); this repository is the v1 snapshot, and the version in use is maintained privately.
Where the data lives
In a SQLite file and an uploads folder beside the program, on the machine that runs it. Nothing is sent anywhere unless the professor configures an e-mail address and a key for notifications. The demo data is fifteen made-up students.
