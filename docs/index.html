Run Letterkeep with your own roster

This workspace uses three fictional records from the application's seed data and eligibility engine. Notes and written status last until reload. The full Flask application runs on your machine.

Student submission and result

The student sees the conditions before submitting their student number, transcript PDF, letter of interest and consent. A PDF grade is used when available, with manual entry as the fallback. The result shows which conditions are met, with roster names and enrolments kept private.

Professor tools

The local professor dashboard has counts, recent checks and a quick student check. Eligible students can be marked written, moved back or removed. Uploaded documents can be downloaded. Roster, import, roster files, documents and threshold/notification settings retain their own pages.

The eligibility rule
  1. The student number must appear in an imported roster.
  2. The grade must meet the threshold, initially 80%. Its source is recorded, including professor overrides.
  3. Attendance must meet the threshold, initially 75%, in every enrolment. A missing rate or one course below the threshold fails this condition.

Roster imports accept common column spellings in any order and case. Course, section, year and term come from the import form. Absence values of 0.04 and 4 both mean four percent.

Run locally 
git clone https://github.com/NickkkLian/Prof-Reference-System.git
cd Prof-Reference-System
python3 -m pip install -r requirements.txt
python3 run_web.py --seed

Python 3.10 or newer. The seed contains fifteen fictional students in two courses. The server listens on this machine at port 5001 and prints separate student and professor addresses. The professor address is the access key. SQLite, rosters and uploads stay on the machine running the app.

Checks, scope and licence 
python3 -m pytest tests -q
python3 break_check.py

This public v1 snapshot was built for a faculty client whose name is withheld. The version in use is maintained privately. Desktop packaging, scanned-transcript OCR and actual email delivery require separate checks. Notifications send only when both an address and an API key are configured.
